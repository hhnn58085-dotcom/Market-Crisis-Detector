# تحليل أسعار السوق وكشف الأزمات والتنبؤ بالأسعار

مشروع تعلّم آلة تعليمي يحلل بيانات أسعار ست سلع أساسية خلال 90 يومًا (540 صفًا)، ويطبّق:
- الاستكشاف والإحصاء الوصفي.
- K-Means لتجميع أيام السوق إلى رخاء / غلاء متوسط / أزمة.
- كشف الشذوذ باستخدام المسافة الإقليدية بعد `StandardScaler` والحد المئوي 95.
- `LinearRegression` للتنبؤ بسعر اليوم التالي، مع تقسيم زمني 80/20.
- `LogisticRegression` للتنبؤ بحالة توفر السلعة.
- محاكاة تفاعلية لثلاثة سيناريوهات.

## تنبيه مهم حول البيانات
ملف التكليف يشير إلى وجود كود جاهز لتوليد البيانات في Starter Notebook، لكنه لم يكن ضمن الملفات المرفقة هنا. لذلك يحتوي هذا المشروع على مولّد بيانات اصطناعية **بديل للتجربة فقط** حتى يعمل المشروع من البداية للنهاية. لا تمثل البيانات أسعارًا حقيقية أو سجلًا موثّقًا للسوق. إذا زوّدك المدرّس بكود التوليد الرسمي، استبدل دالة `generate_market_data()` في `project.py` به دون تغيير منطقها، ثم أعد التشغيل.

## المتطلبات
Python 3.10 أو أحدث موصى به. افتح الطرفية داخل مجلد المشروع ثم نفّذ:

```bash
python -m venv .venv
```

Windows PowerShell:
```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python project.py
```

تشغيل دفتر Jupyter:
```bash
jupyter notebook project.ipynb
```
شغّل الخلايا بالترتيب. السكربت ينشئ `market_data.csv` والرسوم داخل `figures/`.

## الملفات
- `project.ipynb`: دفتر منظم لتشغيل التحليل.
- `project.py`: التنفيذ الكامل للمراحل.
- `requirements.txt`: المكتبات.
- `report.md`: قالب تقرير؛ أضف إليه النتائج الفعلية التي تظهر بعد التشغيل.
- `figures/`: مكان حفظ الرسوم الناتجة.
- `market_data.csv`: يُنشأ عند التشغيل.

## ملاحظات منهجية
- تستخدم مرحلة الانحدار تقسيمًا زمنيًا، لا عشوائيًا.
- يتم ملاءمة `StandardScaler` على بيانات التدريب فقط في الانحدار والتصنيف.
- لا تُستخدم `avail_num` كميزة في نموذج تصنيف التوفر لتجنب تسريب الهدف.
- التجميع غير الموجّه لا يثبت وحده وجود علاقة سببية بين إغلاق المعبر والأزمة؛ النتائج ارتباطية وتُفسّر بحذر.
- لا تُعدّ الدقة المرتفعة ضمانًا لصحة النموذج خارج البيانات الاصطناعية.
