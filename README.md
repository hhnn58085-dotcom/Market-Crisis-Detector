# Market Crisis Detector 📉

## نبذة عن المشروع
مشروع تعلم آلي باستخدام Python لتحليل بيانات الأسواق المالية ودراسة الأنماط والتغيرات غير المعتادة التي قد تشير إلى اضطرابات في السوق.

## أهداف المشروع
- تحليل البيانات باستخدام Python.
- تطبيق تقنيات تعلم الآلة.
- استكشاف التغيرات والأنماط غير المعتادة في بيانات السوق.
- إجراء تحليل يساعد على فهم البيانات المالية.

## التقنيات المستخدمة
- Python
- Jupyter Notebook
- Machine Learning
- Data Analysis

## ملفات المشروع
- `project.ipynb` — دفتر Jupyter Notebook الذي يحتوي على كود المشروع والتحليل.
- `.gitignore` — ملف لتحديد الملفات والمجلدات التي لا يراد رفعها إلى Git.

## طريقة التشغيل
1. نزّل ملفات المشروع من GitHub.
2. افتح `project.ipynb` باستخدام Jupyter Notebook أو Google Colab.
3. شغّل الخلايا بالترتيب.

## تنويه
هذا المشروع تعليمي وتجريبي، ولا يقدم نصائح استثمارية أو يضمن التنبؤ الدقيق بالأزمات المالية المستقبلية.

## المطور
مشروع تطبيقي في تعلم الآلة وتحليل البيانات.
